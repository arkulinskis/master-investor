# Master Investor

A free app that teaches investing from a first index fund to how quants work: valuing a company, where to get data,
portfolio risk, trading, factor models, backtesting and option pricing. Short lessons end with hide-and-reveal
question cards (answer in your head, press Reveal, mark Got it / Not yet), reviewed on a spaced-repetition schedule.
For beginners and advanced traders alike. Built on [Anvil](https://anvil.works) as native Anvil Forms (Python + HTML
templates, a layout, custom components, RepeatingPanels). Look: white like a spreadsheet, green like money.

- **App repo:** github.com/arkulinskis/master-investor (branch `master`). Anvil pulls `master`.
- **Live:** https://master-investor.anvil.app

## What it does

**Learning (open to everyone, no account needed)**
- **9 tracks, 55 lessons, 441 cards**, Beginner to Pro: Foundations, Reading a company, Valuing a company, Markets and
  instruments, Macro and the economy, Portfolio and risk, Trading, The quant's world, Data and tools.
- **Lessons** (`#lesson/<id>`): markdown text with formulas, a worked example with fictional numbers, key terms,
  a link to the matching calculator, "Go further" links, previous / next lesson, and **Share lesson** (the phone's
  share sheet, else the link is copied) pointing at the lesson's public page.
- **Public lesson pages** (`/lessons`, `/lessons/<id>`, server_code/LessonPages.py): every lesson as plain HTML for
  search engines, AI assistants and shared links (summary, text, worked example, terms, the cards as `<details>`
  reveals that work without JavaScript, "Practise these cards in the app"), LearningResource JSON-LD, all in the sitemap.
- **Hide-and-reveal cards** under every lesson: Reveal answer, then Got it / Not yet; "Reveal all" for a quick read.
- **Learn** (`#learn`): track cards with a level filter, lesson search (title, text and terms), continue-where-you-left-off.
- **Track** pages (`#track/<id>`): the lessons as a spreadsheet-style sheet, Start / Continue, Practise this track.
- **Practice** (`#practice`): one card at a time, keys Space / 1 / 2; decks: due for review (members), mixed,
  by level, by track, by lesson, saved lessons, a **12-card placement check** that recommends where to start, and the
  **Hype check** deck (lesson `spotting-hype`: 9 made-up social posts, the reveal names the red flags).
  "Not yet" cards come back once at the end; the end screen lists the misses with answers.
- **Calculators** (`#tools/<calc>`): compound growth with a yearly fee box (lost to fees, value with no fees, dashed
  no-fee line), DCF with a year-by-year table and a sensitivity grid,
  bond price + duration (price/yield curve), option payoff at expiry (chart), Sharpe / Sortino / drawdown from a
  return list (equity curve), position size from a stop, Kelly fraction (growth curve), and the **crash rehearsal**
  (`#tools/crash`): real US yearly returns 1928 to 2025 (Aswath Damodaran, NYU Stern, as published, in
  client_code/history_data.py), a start year, years, stock/bond split (rebalanced yearly) and amount; the chart stops
  at the low point and asks Hold or Move to cash, then reveals kept going vs T-bills after that year, the worst fall
  and the years to recover. Famous-fall presets and a random year.
- **Library** (`#library/<sources|repos|books>`): 32 data sources, 31 GitHub repositories (checked to exist), 18
  books; kind filter and search.
- **Glossary** (`#glossary`): every key term (A to Z, no duplicates), each linked to its lesson.

**Members (free account)**
- **Today** (`#home`): cards ready (due + new from finished lessons), next lesson, this week's chart, streak,
  progress per track, saved lessons.
- Mark lessons done, save for later; every graded card is scheduled (Leitner boxes: 1, 3, 7, 16, 35 days; box 5 =
  mastered; Not yet = back in 10 minutes). Reset my progress on the Profile page.

**Admin**: overview (people, lessons finished, cards reviewed, most finished lessons), users, older feedback, demo
learners (3 fictional learners with progress, removable).

**Landing**: the hero is a small spreadsheet DCF (Harbour Mills) whose answer cell stays hidden until the visitor
presses Reveal (49.95 a share, matching the DCF calculator's defaults); the Watch section (pitch video, loads from
YouTube only on play); the tracks as a ledger; three live cards; FAQ.

## Setting it up in Anvil (once)

1. Anvil editor: **Create app → Clone from GitHub**, paste `https://github.com/arkulinskis/master-investor`.
2. Check the **Users** service (email + password, Continue with Google, sign-up on).
3. Accept the **Schema Mismatch** alert with **"The schema of the source code is correct"**.
4. Run it, sign up with the admin email first, then **Publish**.

## Working on it

See `.claude/skills/masterinvestor/SKILL.md`. In short:

```
python -I tools/content_check.py         # the curriculum's schema and house style -> CONTENT OK
python tools/check.py                    # Anvil's validator, JS syntax, asset hashes, server tests -> ALL CHECKS PASSED
python -I tools/ui_test.py               # the real app in the Anvil App Server (Docker) driven by headless Chrome
python -I tools/ui_test.py --shots DIR   # + screenshots of every page (desktop/phone, light/dark, guest/member)
git push origin master                   # deploy
```
